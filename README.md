# StudyTask - Pencatat Tugas Kuliah

Tugas I - 11S3133 Pengembangan Aplikasi Berbasis Web.
Aplikasi web sederhana (HTML, CSS, JavaScript) yang dikembangkan dengan bantuan AI generatif (Claude).

## Fitur
- Tambah tugas (judul, mata kuliah, deadline, prioritas) dengan validasi
- Tandai selesai, hapus, filter (semua / belum selesai / selesai)
- Penanda "terlambat" dan statistik ringkas
- Data tersimpan di localStorage

## Menjalankan
Buka `index.html` di browser. Tidak perlu instalasi.

## Pengujian
```
node tests/test.js
```

## Struktur
```
index.html   struktur halaman
style.css    tampilan
script.js    logika (fungsi murni + antarmuka)
tests/       uji unit
docs/        Proposal_Tugas_1_StudyTask.docs
```
